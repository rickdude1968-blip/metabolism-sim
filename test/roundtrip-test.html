Regression test — scenario chaining fidelity

What it guards: that continuing a scenario from a saved end-state reproduces an uninterrupted run exactly, variable by variable. If a change to the model ever adds state that the scenario file does not carry, this test goes red.
How to run: serve the app folder (python -m http.server from metabolism-sim/) and open /test/roundtrip-test.html. It runs on load; the banner below is the verdict. A file:// open also works in some browsers. Programmatic result: window.__results.pass.
